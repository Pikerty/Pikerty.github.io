每次修改的测试记录：日期、环境、工具、范围、结果、问题与修复情况。未实际测试的项目明确写 Not Tested，不以「代码已修改」代替「功能已验收」。

每批次一节，含：测试日期 ｜ 变更批次 ｜ 测试环境 ｜ 测试工具 ｜ 测试范围 ｜ 结果 ｜ 发现的问题 ｜ 修复情况 ｜ 尚未解决的问题。

1. HTML 结构检查 2. CSS 语法检查 3. JavaScript 语法检查 4. 图片资源路径检查 5. 桌面与移动布局检查（360/390/640/768/1024/1280/1440 七视口） 6. 深/浅主题检查 7. 9 种语言切换检查 8. 首页搜索与筛选检查 9. 文章页面跳转检查 10. 控制台错误检查
